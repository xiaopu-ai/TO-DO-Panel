# 架构与 UI / 性能审查（2026-11-10）

本轮已改的内容见 git diff；这里只记录**审查发现但尚未处理**的问题，按影响排序。

## 架构

- `main.js` 约 3800 行，是一个持有 40+ 个模块级可变状态的单文件：窗口状态机、提醒队列、剪贴板、转写 WebSocket、密钥库、链接抓取、待办收件箱全在一起。本轮只把新增能力放进了 `main/`，旧代码未拆。建议按「窗口 / 岛 / 剪贴板 / 转写 / 密钥 / 收件箱」逐个迁出，每个模块只导出 `start/stop` 与 IPC 注册。
- 渲染层 `app.js`（3900 行）+ `workspace.js`（2700 行）+ `styles.css`（5400 行）同样是单文件；所有 Tab 在启动时全部构建，没有按需加载。
- 主面板 preload 向同一个页面暴露了全部 80 个 IPC（含密钥、文件读写）。岛与权限窗口已改用各自的最小 preload，主面板未动。
- 系统能力依赖 `osascript`（窗口枚举、图标、前台应用、汽水音乐、粘贴），每次调用都是一次进程启动。真正的解法是一个常驻的原生 helper，这与已被推翻的 ADR 0001 不同：只做服务层，不重写界面。
- `styles.css` 有两个 `:root`（第 1 行与约第 2600 行），后者静默覆盖前者：`--bg-base` 变成 `#050506`、`--r-panel` 变成 28px，并加了彩色锥形描边，与 CLAUDE.md 的「纯黑、16px、单色」规则矛盾。需要决定以哪边为准后合并。
- `main-services.js` 里的 `screenRecordingProbePolicy` 已无调用方（权限窗口直接读系统状态）。

## 性能（未处理）

1. 8 个 Tab 始终参与布局，窗口 200px ↔ 1240px 每次都整体重排。给 `.panel` 固定展开尺寸、非激活 Tab 用 `content-visibility: hidden`。
2. 展开 / 收起在全窗口伪元素上过渡 `clip-path`，上面还有一层 mask 合成的锥形渐变描边。需要用 Performance 面板确认是否走合成器；若不是，改为 `transform: scale` 或去掉描边。
3. `effects.js` 的列表悬停效果：每次 `pointermove` 对列表里每一项调 `getBoundingClientRect`，每帧遍历全文档的 `[data-line-sidebar-item]`；`#panels` 上的 subtree MutationObserver 在任何 DOM 变化时重跑。
4. 镜子的液态悬停：鼠标离开后 `feTurbulence` 滤镜还要逐帧衰减约 2 秒。
5. 录音可视化在面板折叠或切到别的 Tab 时仍以 60fps 跑带 `context.filter = blur()` 的绘制。
6. `windows:list` 每次都把所有图标的 base64 随结果一起过 IPC（本轮只做了「没变就不重建 DOM」）。

## UI / 交互（未处理）

- 删除撤销已补（指令、链接、分组、录音、密钥、笔记、待办批量）。密钥与录音在撤销窗口内退出应用时，真正的删除可能来不及执行：密钥会留在保险库里，录音的音频文件会成为孤儿文件。
- API 设置对话框标了 `aria-modal` 但没有焦点陷阱，背后的面板也没有 `inert`（本轮只补了 Esc 关闭与焦点归还）。
- 日期弹层：日期按钮高 17px、月份箭头 20×20；过去的日期可点、点完才报错；触发按钮缺 `aria-expanded`。
- 密钥卡片 `tabIndex=0` 但只响应点击，键盘无法进入编辑。
- 快捷键录制器对所有按键 `preventDefault`（包括 Tab），「取消」无法用键盘到达。
- 多个文字按钮命中区不足 24px：`.api-key-help`、`.bulk-delete`、`.windows-hidden`、`.windows-refresh`、密钥行内操作按钮。
- 截断文本没有 `title`：链接、录音、密钥、笔记列表行。
- 恢复隐藏窗口的按钮显示文字是「隐藏」。
- `#credential-password` 是 `type="text"`，没有显示 / 隐藏切换。
- 硬编码：146 处字号、287 行字面颜色（49 种十六进制值、38 种白色透明度）、36 种圆角值；成功绿 4 种、错误红 7 种、蓝 6 种以上，各应收敛为一个 token。
- 死 CSS：至少 49 个类名在 HTML 与 JS 中都不存在（`home-clock`、`note-preview`、`home-character`、`music-artwork*`、`pomodoro-progress*`、`note-library*` 等），91 个选择器被原样重复声明（`.topbar` 4 次、`.home-pomodoro` 组 4 次）。
- 减弱动态效果：WAAPI 动画（密钥展开）与 JS 驱动的动效（Dock 放大、镜子水波）未受 `prefers-reduced-motion` 约束。
