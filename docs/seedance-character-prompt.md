# 灵动岛 3D 人物 · Seedance 图生视频提示词

## 推荐设置

- 模式：图生视频（首帧使用 `docs/assets/notch-character.png`）
- 模型：Seedance 2.0
- 时长：5 秒
- 比例：9:16
- 镜头：固定
- 运动幅度：中低
- 背景：纯色绿幕，后续在 Electron 中抠成透明视频

## 主提示词

保持参考图中 3D 男性角色的身份、面部五官、蓝色眼睛、黑色短发、蓝黑色机能夹克、材质和配色完全一致。角色从画面下方自然探出上半身，双前臂轻松趴在画面底部一条不可见的水平组件边缘上，身体重心真实地压在边缘上。开始 0.4 秒保持安静并看向镜头；随后露出克制、友好的微笑，抬起右手向用户自然挥手两次，同时轻微眨眼和点头，像每次工作台展开时向熟悉的主人打招呼；动作结束后右手放回边缘，恢复到最开始的趴靠姿势，方便自然循环。动作轻盈、细腻、有高级 3D 游戏角色质感，头发和衣领只有很轻的惯性摆动。固定机位，正面中近景，人物始终保持在画面中央偏下，头顶与左右留出安全边距。背景必须是完全均匀、无渐变、无阴影、无反光、无绿色溢色的纯色 #00FF00 绿幕，人物脚下和背后都没有任何物体。

## 负向提示词

不要改变人物长相、年龄、发型、眼睛颜色、服装、夹克文字和材质；不要增加或减少手指、手臂、饰品；不要出现肢体穿插、手指粘连、面部漂移、嘴型说话、夸张表情、快速动作；不要推拉、摇移、旋转、景深变化或镜头抖动；不要加入桌子、栏杆、房间、风景、文字、字幕、标志、水印、粒子和额外人物；不要裁掉头顶、手掌、手肘和肩膀；不要产生绿幕阴影、渐变、噪点或绿色反光。

## 后期接入说明

Seedance 常规视频不带 Alpha 通道。导出后先用绿幕抠像转为透明 WebM，再放入首页人物模块；首尾姿势一致，可在每次展开时从头播放一次，结束后停在末帧。
