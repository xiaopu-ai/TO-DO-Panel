# 常用应用（方案 1）

**Goal：** 在设置中管理常用 `.app`，首页「常用应用」组件一键启动；启动后保持面板展开。

## 行为

- 设置右侧「常用应用」卡片：已选拖拽排序 / 移除 / 点击启动；本机列表勾选；「选择…」访达添加
- 首页模块 `apps`：图标网格，medium+ 显示名称，small/mini 藏名称；空态跳转设置
- 上限 24；存储 `notch-app-favorites`
- IPC：`apps:list` / `apps:icons` / `apps:pick` / `apps:launch`（仅绝对路径且以 `.app` 结尾）

## 非目标

- 不恢复独立应用 Tab
- 不占全局快捷键
- 启动后不自动收起
