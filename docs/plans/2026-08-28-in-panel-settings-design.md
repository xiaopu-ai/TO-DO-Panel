# 面板内设置中心设计

## 背景与目标

TO-DO Panel 的菜单栏图标在刘海屏 Mac 上可能被物理刘海遮挡。当菜单栏图标过多时，用户无法点开托盘菜单，也就无法替换 API Key、镜子配图、快捷键或数据目录。设置能力必须同时存在于菜单栏和展开面板内，两处读写同一份主进程配置，任何一侧的修改都立即反映到另一侧。

## 产品范围

在顶部 Tab 最右侧新增「设置」。它与「首页」一样始终可见，不属于可关闭功能，也不会出现在「显示功能」开关列表中。设置页包含：

- API 配置：显示通义百炼实时转写与 DeepSeek 的安全存储状态，并复用现有 API 配置面板完成录入或替换。
- 首页镜子：显示当前镜子封面预览，通过系统文件选择器替换图片。
- 显示功能：控制待办、笔记、链接、录制、密钥与剪贴板 Tab；首页和设置不可关闭。
- 唤出快捷键：显示当前快捷键，复用现有按键录制浮层重新设置。
- 数据文件夹：显示当前路径，可在访达打开或更换目录。
- 开机自动启动：直接切换 Electron 登录项状态。

「关于」与「退出」不是配置项，继续只放在菜单栏中。

## 交互与视觉

设置页采用与现有工作台一致的深色玻璃视觉，内容为两列卡片网格，而不是 macOS 系统设置的侧栏复制品。左列放高频配置（API、显示功能），右列放设备与本地配置（镜子、快捷键、数据目录、开机启动）。卡片标题、状态徽标与按钮都复用现有 CSS 变量和按钮语言；不新增字体、第三方组件或构建步骤。

镜子卡片直接显示当前封面，替换成功后由主进程广播 `mirror:image-changed`，首页与设置页预览同时刷新。功能开关修改后由主进程保存 `app-settings.json` 并广播 `settings:changed`，Tab 导航与设置开关同步刷新。切换设置 Tab 时刷新所有状态，避免从菜单栏修改后显示陈旧信息。

## Electron 边界与数据流

所有系统级操作继续由主进程执行：

- `settings:set-feature` 只接受白名单功能 ID 与布尔值，保存后调用现有 `applyAppSettings()`。
- `settings:set-auto-launch` 调用现有登录项函数并返回最终状态。
- `mirror:choose-image` 复用现有图片校验、JPEG 转换与写入逻辑，并返回取消、成功或失败结果。
- 工作区打开/更换、快捷键和 API 配置继续复用现有 IPC。

`preload.js` 仅暴露上述窄接口；渲染进程不直接访问 Electron、文件系统、登录项或明文密钥。API Key 输入框仍不回显已保存的明文，状态只显示「已安全保存 / 需重新输入 / 未配置」。

## 错误处理与验收

取消图片或目录选择不是错误，不显示失败提示。主进程保存失败、图片无效、快捷键被占用或登录项切换失败时，设置页保留原状态并显示现有状态 Toast 或卡片内错误提示。设置 Tab 被选中时离开首页，必须沿用现有逻辑立即释放摄像头。

验收标准：设置 Tab 始终位于导航最右侧；关闭任意可选功能不会隐藏设置；菜单栏和设置页的开关互相同步；API、镜子、快捷键、数据目录和开机启动均可在不访问菜单栏图标的情况下操作；完整测试与语法检查通过。
