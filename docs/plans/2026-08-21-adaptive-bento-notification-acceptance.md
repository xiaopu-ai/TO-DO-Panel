# NotchTodo 自适应 Bento 与提醒验收实施计划

**目标：** 把首页从固定槽位改成可调整尺寸的无边框 Bento 工作台，同时提升窗口识别、任务定位、提醒、待办分类、镜子和录音反馈的可用性。

**架构：** 保持 Electron 主进程、preload 与原生 HTML/CSS/JavaScript 的现有边界。可测试的命名、分类、音量和布局约束放入 `renderer/domain.js`；系统窗口和任务通知归一化放在主进程；视觉动效由 CSS、Canvas 与 Web Animations API 完成，不引入 React 构建链。

### Task 1：领域行为与回归测试

- 为 VS Code/Cursor 工作区标题提取、同名窗口消歧、待办分类迁移、组件尺寸约束和录音音量计算先写失败测试。
- 逐项实现最小纯函数，并保持旧 LocalStorage 数据可读。

### Task 2：窗口与提醒数据链

- 保留 CGWindow 的真实窗口标题，在渲染层显示工作区/仓库名并用完整标题做 tooltip。
- Codex/GPT 完成事件优先显示工作目录对应项目与具体任务摘要。
- 通知保持独立的 `400 × 96` 非激活窗口，分别提供 Codex、GPT、DDL 三类视觉状态，不触发主面板展开。
- 修复窗口长按拖出后指针取消、失焦或收起时未清理移除态的问题。

### Task 3：可变尺寸 Bento 首页

- 移除日期时间卡片，加入透明人物占位模块。
- 首页组件提供小/中/大三档尺寸；本地持久化尺寸与顺序，调整时自动压缩其他组件以保证两行内容区不溢出。
- 每次展开先切回首页，再播放组件逐个上移渐显。
- 首页卡片取消描边，统一圆角、阴影、字体和 Lucide 线性图标运动规范。

### Task 4：待办、镜子与录音反馈

- P0–P3 存储键保持不变，默认显示名迁移为“课程 / 自媒体&写作 / Vibe coding / 日常”，标题可直接编辑。
- 镜子在首页揭示结束后播放像素揭示；悬停以 Canvas 波纹轨迹叠加 SVG 位移，延长扰动尾迹。
- 录音建立 Web Audio Analyser，Canvas Strands 按实时 RMS 音量改变幅度和速度；暂停与结束正确释放音频节点。

### Task 5：验收

- 运行完整 `npm test` 和语法检查。
- 启动 Electron，验证默认首页、工作区名称、可变尺寸、拖拽清理、镜子和录音状态。
- 分别触发 Codex、GPT、DDL 提醒并保存三张验收截图。
- 提供 Seedance 图生视频提示词；在视频交付前使用透明 PNG 作为低成本占位动效。
