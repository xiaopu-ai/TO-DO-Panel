# 首页媒体与窗口交互设计

## 目标

- 录音继续本地保存，同时可选接入百炼 Qwen3-ASR 实时 WebSocket；未配置云端凭证时明确降级为“仅录音”。
- 镜子保持 1:1，通过悬停滚轮或触控板双指手势做 100%–300% 数字变焦，双击复位。
- 当前窗口改为应用图标网格，只显示图标和应用名；同一应用多窗口按 `应用名-1`、`应用名-2` 编号。
- 长按窗口图标后拖出当前窗口卡片即可隐藏；隐藏项保存在 LocalStorage，并提供一键恢复入口。

## 数据与安全

- 麦克风同时连接 MediaRecorder（本地音频）与 Web Audio（16 kHz PCM 转写流），暂停和结束时同步控制。
- 百炼 API Key 只通过 preload 进入主进程，使用 Electron `safeStorage` 加密后写入 `userData`；渲染层只能读取“是否已配置”。
- WebSocket 由主进程建立并添加 Authorization 请求头，渲染层无法读取密钥。
- 当前窗口图标由主进程根据 macOS 进程的 `.app` 路径获取；窗口聚焦仍只接受最近扫描缓存里的 ID。

## 失败与降级

- 未配置或云端连接失败：不中断录音，首页显示具体状态，录音资料库仍保存音频。
- 图标读取失败：回退到应用首字母。
- 拖拽隐藏可通过“已隐藏 N”恢复，避免不可逆移除。
