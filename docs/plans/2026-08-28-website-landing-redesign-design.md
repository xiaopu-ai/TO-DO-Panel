# TO-DO Panel 官网落地页重构设计

## 目标

将现有官网重构为一套深色、3D、编辑式大排版的产品落地页。页面沿用参考 3D Creator 站点的章节节奏与核心交互，但所有内容、素材和功能叙事均服务于 TO-DO Panel。

首屏是唯一转化入口，也是第一个视觉记忆点；后续页面依次完成操作预览、产品定位、能力说明、六个 Tab 展示、本地隐私说明和品牌收尾。

## 视觉系统

- 固定深色主题，主背景 `#0C0C0C`。
- 主文字 `#D7E2EA`，次级文字 `#7B828C`，细边框使用低透明银灰。
- 英文大标题采用 Kanit，中文采用 Noto Sans SC。
- 英文标题、章节编号和导航负责视觉节奏；产品说明、按钮和功能描述以中文为主。
- 大标题使用 `#646973 → #BBCCD7` 的银灰纵向渐变。
- 主按钮保留紫、洋红、橙色渐变；两个转化按钮只出现在首屏。
- 大型 Tab 卡片使用 40–60px 圆角，媒体内容必须完整显示，不允许裁切产品面板。

## 页面架构

### 01 Hero

- 顶部导航展示品牌、ABOUT、FEATURES、TABS、PRIVACY。
- 超大 `TO-DO PANEL` 横跨首屏上部。
- 主体保持左文右图：左侧只有产品标签、双行中文主标题和两个按钮；右侧展示真实首页面板。
- 右侧面板响应鼠标位置产生 Magnet 位移与轻微透视旋转，离开后弹性复位。
- 首屏加载使用分段进入动画，先导航和大标题，再左侧文案，最后真实面板。

### 02 Operation Marquee

- 两排真实操作录屏，随页面滚动反向移动。
- 素材内容覆盖首页展开、待办、剪贴、笔记、链接、录制、密钥和 AI 完成提醒。
- 未提供录屏时显示统一的素材缺失状态，不创建模拟产品界面。

### 03 Product Transition

- 深色整屏过渡页，超大 `ONE PLACE` 标题。
- 中央仅保留一段精炼产品定位文案。
- 四角使用 3D 装饰物，不放按钮。

### 04 Capabilities

- 浅色圆角章节，对应参考站点的 Services Section。
- 使用超大 `WHAT IT DOES` 标题和六条纵向或网格能力说明。
- 内容包括贴顶工作台、任务提醒、内容收集、本地录音、AI 完成提醒和本机数据。

### 05 Tab Introduction

- 深色整屏章节，以 `EVERY TAB` 引入卡片堆叠。
- 只解释继续滚动会依次看到六个工作空间。

### 06–11 Tab Stack

- 顺序固定为待办、剪贴、笔记、链接、录制、密钥。
- 每张卡片表头只有大编号、英文短标签、Tab 名称和一句中文说明。
- 卡片主体由一张完整真实面板截图占满。
- 卡片滚动到顶部后固定，下一张从下方覆盖；上一张轻微缩小形成纵深。
- 不提供查看按钮，不拆分多个 UI 细节组件。

### 12 Privacy

- 用简单数据流说明内容保存在当前 Mac。
- 强调无强制云账号、无公网通知端口和无行为追踪。
- 说明只有用户主动配置转写服务后，对应音频才会发送。

### 13 Ending

- 只保留应用图标、一个英文收尾标题和极简页脚。
- 不重复下载按钮，不增加长说明。

## 真实素材约束

- 禁止通过代码、生成图片或重绘方式构造虚假产品 UI。
- 首页、六个 Tab 和跑马灯只允许使用真实产品截图或真实操作录屏。
- 网站已有真实截图可以机械裁切与压缩，但不得改变界面结构和内容关系。
- 正式素材应隐藏密钥、账号和其他不适合公开的信息。
- 图片使用 `object-fit: contain`，保留真实宽高比。
- 媒体加载失败时回退到同功能的真实静态截图；若截图也不存在，则显示无界面图形的中性素材状态。

## 动效规则

- Hero 面板最大水平位移 18px、垂直位移 12px，旋转不超过 1.5°。
- Magnet 进入使用约 300ms ease-out，离开使用约 600ms 弹性复位。
- 跑马灯只在进入视口后更新位置，滚动监听必须是被动的或由 Motion 值驱动。
- Tab 卡片目标缩放范围为 `0.94–1`，每张卡片保持独立 Sticky 容器。
- 移动端关闭 Magnet 和大幅透视，Tab 卡片改为自然纵向排列。
- `prefers-reduced-motion` 下关闭跟随、跑马灯位移、逐字点亮和卡片缩放。

## 技术方案

- 保留 React 19、Vinext、TypeScript 和原生 CSS。
- 不迁移 Tailwind，不引入 Lucide。
- 使用 Framer Motion 管理滚动进度、视口进入和卡片缩放。
- 页面组件按职责拆分，文案与素材配置集中管理。
- Magnet 数学计算放在纯函数模块中，以 Node 测试覆盖边界和 reduced-motion 降级。

## 验收标准

- 首屏在桌面端明确保持左文右图，真实面板可随指针轻微移动。
- 页面只有首屏出现“下载 macOS 版本”和“查看 GitHub 仓库”两个按钮。
- 六张 Tab 卡片各只有一句说明和一张完整真实截图。
- 不存在模拟或生成的产品 UI。
- 320px 起可用，桌面宽屏不出现标题孤行、媒体裁切或水平滚动。
- 官网测试、ESLint 和生产构建通过。
- 动画在 reduced-motion 环境下正确降级。
