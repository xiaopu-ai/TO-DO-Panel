# Dynamic Panel 列表、链接、剪贴板与通知交互修正

> **本文已于 2026-08-25 作废。** 原生刘海壳已从仓库移除，项目回到单一 Electron 架构；
> 原因见 [adr/0001-native-macos-architecture.md](../adr/0001-native-macos-architecture.md) 文首说明。
> 以下内容保留为历史记录。

## 目标

修正当前面板中的快捷键冲突、待办顺序、链接分组、列表 hover、密钥检索、剪贴板回填与原生灵动岛通知遮挡。默认只保留 Hover + Space 展开/收起面板，不再注册 `Command + Shift + V` 或其他内置快捷键。

## 交互与数据设计

### 待办

每个 P0–P3 分类内使用同一稳定排序：未完成在前，已完成在后；同状态按 DDL 从早到晚；DDL 相同按 `createdAt` 从早到晚；数据缺失时使用 ID 作最后稳定键。排序仅决定展示顺序，不破坏 LocalStorage 中的原始条目。新增、修改 DDL、勾选完成时先采集 DOM 旧位置，重排后通过 Web Animations API 执行纵向 FLIP；开启 `prefers-reduced-motion` 时直接重排。

### 链接

顶部输入仍支持自动分组，但分组决策先检查现有链接的主机名：同主机或父子域名命中时必须复用已有分组，避免大模型生成近义分组。每个分组删除按钮左侧增加添加按钮，点击后在组内显示输入行；该入口创建的链接固定留在目标组，后台只补全标题和图标。链接行使用原生 HTML Drag and Drop，按住后可纵向拖到其他分组；落点组显示高亮，放下后持久化新归属。

### 列表与密钥

待办、链接、录音、密钥统一使用待办列表的左侧竖向色条、轻微背景渐变和最多 3px 水平位移，删除当前会穿出容器的横线。密钥列表头部增加关键词输入，按服务名和账号不区分大小写匹配。移除首字母图标列，卡片改为左对齐的“服务名 / 账号 / 密码掩码”两列布局。

### 剪贴板

剪贴板轮询与前端入口完全解耦：应用就绪后始终记录，前端隐藏不停止服务，也不注册全局剪贴板快捷键。展开面板前记住当时的外部前台应用。点击剪贴记录时先写回系统剪贴板，收起面板，再激活原应用并发送 `Command + V`。系统辅助功能权限不可用时，保留“已复制”降级，不丢失用户内容。

### 原生通知

正常混合模式继续使用 SwiftUI + AppKit 的原生灵动岛形变，Electron 通知窗口只作原生壳不可用时的降级。`liveActivity` 内容区顶部增加实际菜单栏/安全区高度，使图标、标题和详情完全落在物理刘海下方。离屏快照固定使用 33pt 安全区，便于自动检查。

## 验收

- 状态栏只展示面板快捷键设置，默认为 Space；`Command + Shift + V` 不再被占用。
- 任何待办变更后顺序符合比较器，并以纵向位置动画过渡。
- 分组可定向添加，链接可跨组拖拽，同域名自动复用旧组。
- 密钥可搜索，无首字母图标；各列表 hover 不再出现横线穿模。
- 关闭剪贴板前端时仍会记录；点击条目能回填到原输入框，失败时有复制降级。
- 原生通知文字与图标不与 33pt 物理刘海安全区重叠。
