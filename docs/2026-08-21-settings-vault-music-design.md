# 系统配置、密钥与音乐组件设计

## 目标

- 将菜单栏下拉菜单收敛为启动项、API 配置、镜子换图、关于和退出。
- 在渲染层之外保存 API Key 与账号密码，避免明文进入 LocalStorage。
- 用本地汽水音乐控制组件替代首页人物图片。
- 为待办增加基于创建时间与截止时间的剩余时间电量。
- 统一支持 Shift 范围多选和批量删除的数据列表。
- 将录音反馈改为随音量变化的弥散多彩体积波。

## 安全边界

密码库由主进程读写 `userData/credentials.vault.json`，整个有效载荷使用 Electron `safeStorage` 加密。渲染层读取到的条目只包含服务名、账号和固定掩码；复制账号或密码时，只提交条目 ID 和字段名，由主进程解密并直接写入系统剪贴板。

API 配置延续同一原则：转写与 OpenAI-compatible 智能命名配置保存在主进程，公开配置只返回“是否已配置”和非敏感字段。菜单入口只负责展开应用并打开配置面板。

## 时间电量

剩余比例定义为：

`clamp((deadline - now) / (deadline - createdAt), 0, 1)`

已过期为 0%；创建时间缺失或晚于截止时间时，不显示电量。颜色阈值为：80% 及以上绿色、50%–80% 黄色、30%–50% 橙色、30% 及以下红色。

## 汽水音乐

组件显示汽水音乐应用图标、连接状态和上一首 / 播放暂停 / 下一首。首次操作会唤起已安装的汽水音乐，播放控制通过 macOS 系统媒体键发送，避免依赖汽水音乐内部 DOM。应用没有公开的稳定播放信息接口，因此首版不伪造曲名和封面。

## 列表交互

普通点击维持原有主操作；Shift 点击进入范围多选，保留上一次锚点并选中连续区间。选中后显示批量删除入口，Esc 清空选择。录音、链接、常用指令、待办和密钥采用相同的选中视觉。

## 录音动效

Canvas 使用对称的填充波瓣、宽模糊和 `lighter` 叠加，音量同时驱动高度、亮度与扩散半径。静止时保留低亮度呼吸，录音时形成青、蓝、紫、粉、金的连续弥散光场。
